# helloasib.com

Personal portfolio of **Asib Uz Zaman**, Creative Designer (Dhaka, BD).

Current release: **hero section only**. The full portfolio is on its way.

- Plain static site: `index.html` + `img/`, no build step
- GSAP (CDN) for the intro animation; Sofia Sans Condensed + Spline Sans Mono (Google Fonts)
- Hosted on Vercel → https://helloasib.com

## Run locally
Open `index.html`, or run `npx serve .`
